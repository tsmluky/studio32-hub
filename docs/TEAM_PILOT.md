# Studio32 Hub: piloto de equipo

## La promesa

Abrir una sola pantalla y entender en menos de un minuto:

- Qué importa hoy.
- En qué está cada persona.
- Qué está bloqueado.
- Qué ocurre en la agenda.
- Cuál es el siguiente hito de cada proyecto.

El Hub no intenta sustituir Drive, Calendar o Notion. Los conecta con el trabajo diario y evita que el contexto quede repartido entre conversaciones y carpetas.

## Presentación al equipo

1. Entrar como Juanma, Pancho o Gonzalo.
2. Mostrar `Equipo hoy` y actualizar el foco de una persona.
3. Completar una tarea y comprobar cómo cambia el progreso del proyecto.
4. Añadir un bloque a la agenda.
5. Capturar una nota o decisión y enviarla a un proyecto.
6. Abrir un proyecto para ver tareas, conversación, decisiones, pizarra y entregables juntos.

La demostración debe durar menos de cinco minutos. El mensaje no es "tenemos otra herramienta", sino "ya no tenemos que preguntar dónde está cada cosa para empezar el día".

## Hábito mínimo durante una semana

- **Al empezar:** cada persona deja una frase en `Equipo hoy`.
- **Durante el día:** cualquier tarea, nota, decisión o enlace se captura en el Hub.
- **Antes de terminar:** se ordena el Inbox y se actualizan los bloqueos.
- **Una vez por semana:** se revisan los proyectos, sus hitos y el trabajo que sigue abierto.

## Señales de que funciona

- Los tres miembros entran sin que nadie tenga que recordarlo.
- La puesta al día diaria puede hacerse leyendo la pantalla.
- Disminuyen las preguntas sobre responsables, archivos y próximos pasos.
- Las decisiones quedan dentro de su proyecto.
- El Inbox vuelve a cero con regularidad.

Si una sección no ayuda a tomar una decisión o avanzar trabajo durante el piloto, se simplifica o se elimina.

## Lo siguiente para uso real

La interfaz ya permite validar el hábito. Para convertirla en el sistema compartido definitivo hacen falta:

1. Autenticación real para las tres cuentas `@studio32.es`.
2. Base de datos compartida y actualizaciones en tiempo real.
3. Sincronización de Calendar y enlaces de Drive.
4. Copias de seguridad y registro básico de actividad.
